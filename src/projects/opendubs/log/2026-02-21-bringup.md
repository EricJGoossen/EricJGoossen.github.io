OpenDubs runs on an NVIDIA Jetson Thor, so the first job was getting it ready for the whole team. I flashed JetPack onto it, got its IO talking to the rest of the robot, and set up the Docker environment we all develop in: a ROS 2 image with the build tools, Makefile and VS Code tasks to build and debug inside it, and per-person git identities so four people can commit from one shared machine.
{% endrow %}

{% row "images/bringup-first-drive.mp4", "The rover base, with no arms yet, driving down a long hallway while a person walks ahead of it", { poster: "images/bringup-first-drive.jpg", caption: "The base driving down the hallway, August 28.", more: [{ src: "images/bringup-full-robot-drive.mp4", poster: "images/bringup-full-robot-drive.jpg", alt: "The full robot, arms mounted on a column above the base, driving and turning in the lab", caption: "With the arms on, September 10." }] } %}
The base drives four mecanum wheels through a Pixhawk running ArduPilot, over MAVROS. With another intern, I brought up the drive code, then added what the rest of the stack needed: a URDF and an SDF with collision geometry for RViz and Gazebo, and a [service that records topics to rosbags](https://github.com/EricJGoossen/rosbag_recorder). Every test after this was a bag I could replay.
{% endrow %}

The base carries everything else: a 51.2 V LiFePO4 battery, an emergency stop on the deck and a status display, all wired into one aluminum frame. The arms, the Thor and the lidars all ride on top of it.
